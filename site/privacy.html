Open Procurement

Confidențialitate

Pe scurt: site-ul nu vă urmărește. Nu setează niciun cookie, nu rulează niciun instrument de analiză sau de măsurare a audienței, nu are conturi și nu are formulare.

Cine operează site-ul

Cristian Nichifor, autorul proiectului. Pentru orice întrebare despre această pagină sau despre date, deschideți un issue: https://github.com/CristianNichifor/open-procurement/issues

Ce rulează în browserul dumneavoastră

  • Niciun cookie și nicio stocare locală. Pagina nu scrie nimic în browser în afara memoriei cache obișnuite, pe care browserul o gestionează singur.
  • Niciun instrument de analiză. Nu există scripturi de statistici, pixeli sau servicii de măsurare a traficului.
  • Căutarea rulează local. Interogările se execută în browser, cu DuckDB-Wasm, peste fișiere de date publice. Ce căutați nu este trimis nicăieri.

Cine primește cererile tehnice

Orice pagină web ajunge la dumneavoastră printr-un server, care primește datele tehnice pe care le poartă orice cerere: adresa IP, tipul browserului și adresa paginii cerute.

  • Găzduire: Cloudflare Pages (projects.cristian-nichifor.com). Adresa mai veche a proiectului, cristiannichifor.github.io/open-procurement/, este servită de GitHub Pages.
  • CDN: motorul de interogare DuckDB-Wasm se descarcă de la cdn.jsdelivr.net, iar cele două extensii ale lui care citesc fișierele de date (parquet, httpfs) de la extensions.duckdb.org. Acestea sunt singurele cereri către terți pe care le face pagina.

Codul site-ului nu înregistrează nimic despre vizitatori.

Legături externe

Linkurile către data.gov.ro, GitHub sau alte site-uri duc la servicii cu propriile reguli de confidențialitate și sunt accesate doar dacă dați clic pe ele.

Datele publicate

Datele provin din surse oficiale publice și numesc autorități și firme. Dacă o înregistrare este greșită sau vă privește și doriți să răspundeți, vedeți dreptul la replică.

Privacy

In short: this site does not track you. It sets no cookies, runs no analytics or audience measurement, has no accounts and no forms.

Who runs the site

Cristian Nichifor, the author of the project. For any question about this page or the data, open an issue: https://github.com/CristianNichifor/open-procurement/issues

What runs in your browser

  • No cookies and no local storage. The page writes nothing to your browser beyond the ordinary cache, which the browser manages itself.
  • No analytics. There are no statistics scripts, pixels or traffic-measurement services.
  • Search runs locally. Queries execute in your browser with DuckDB-Wasm, over public data files. What you search for is not sent anywhere.

Who receives the technical requests

Every web page reaches you through a server, which receives the technical data any request carries: IP address, browser type and the address requested.

  • Hosting: Cloudflare Pages (projects.cristian-nichifor.com). The project's older address, cristiannichifor.github.io/open-procurement/, is served by GitHub Pages.
  • CDN: the DuckDB-Wasm query engine is downloaded from cdn.jsdelivr.net, and the two extensions it uses to read the data files (parquet, httpfs) from extensions.duckdb.org. These are the only third-party requests the page makes.

The site's own code records nothing about visitors.

External links

Links to data.gov.ro, GitHub or other sites lead to services with their own privacy rules, and are only fetched if you click them.

The published data

The data comes from official public sources and names contracting authorities and companies. If a record is wrong, or concerns you and you want to respond, see the right of reply.
